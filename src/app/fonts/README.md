# Fraunces

Fraunces SemiBold, normal and italic, at optical size 72. These are the exact static font files from the approved C preview.

Source: Google Fonts CSS API, `https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,72,600;1,72,600&display=swap`.
License: SIL Open Font License 1.1 (see OFL.txt).

Loaded locally with next/font/local. Manrope remains the main display face and DM Sans the body face. Fraunces italic is the hero accent; regular Fraunces is used for homepage section headings.
